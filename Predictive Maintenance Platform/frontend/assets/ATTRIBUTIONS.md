# Asset Attributions

## 3D Models (.glb)

All current 3D models (centrifugal_pump.glb, induction_motor.glb, air_compressor.glb, industrial_gearbox.glb, cnc_machine.glb) are **Illustrative Engineering Models** procedurally generated for this project using 	rimesh. They accurately map the required component hierarchy but do not represent specific CAD assets.

**Source**: Procedurally generated via Python script (ackend/generate_3d_models.py).
